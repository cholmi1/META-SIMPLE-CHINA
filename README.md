## 특징
- 60대 이상 사용 가능: 글자 19px+, 버튼 56px, 글자크게 3단계
- 컬러 디자인: 네이비 #1E3A8A + 앰버 #F59E0B
- 기사에게 보여주기: 중문 52px 전체화면
- 항공·호텔 탭: PDF 뷰어 내장
